(`MANIFEST.csv`, `tidy/rtdsm/rtdsm_vintage_summary.csv`). Nothing here is fitted. The ranking uses

## What the ranking leaves out, and why
- **Weekly Economic Index (WEI)**: ALFRED vintages exist only from 2020-04. The first print differs from the latest in 99% of weeks, so it is a revised model output. Collected for reference; not recommended.
- **Excess bond premium, Chauvet–Piger probabilities, CFNAI**: model-estimated or re-estimated. CFNAI and Chauvet–Piger vintages are already on disk (186, 27).
- **Conference Board consumer confidence, NFIB, Chicago PMI**: licensed or PDF-only. Not collected.

## Method notes that matter for the walk from 1948
1. **RTDSM `asof`** is the 15th of the vintage month. Release-day precision needs a calendar: the BLS release dates for 1966–2010 are in `tidy/rtdsm/bls_employment_situation_release_dates_long.csv`, and ALFRED `realtime_start` covers later years. Use `first_pct_chg_within_vintage`, not differences of `first_value`: IP index bases change between vintages.
2. **Back-filled history is flagged** (`is_backfill`) in the RTDSM and ALFRED first-print files. An observation that first appeared more than 130 days (monthly) or 200 days (quarterly) after its date entered as history, not news.
3. **SPF release dates** are known only from 1990Q2. `release_date_assumed` uses quarter-end before that, which is later than the probable release, so it is conservative.
4. **UMich `asof_assumed`**: end of reference month (monthly, 1978 on); end of the month after quarter-end for the 1960–77 quarterly surveys (assumption).
5. **EIA `asof_assumed`**: week end + 5 days (Wednesday release).
6. **Keyless ALFRED**: `code/fetch_alfred_keyless.py` gets the full real-time-period history for any ALFRED series without an API key, by POSTing the `downloaddata` form with every vintage selected. The existing `186/code/fetch_vintages.py` needs the FRED key pool on the Mac.

## Blocked or unresolved routes (what was tried)
- **Beige Book sentiment indices** (openICPSR project 205881): HTTP 403 to a plain client, and downloads need a login. Not attempted (no credentials).
- **ISM/NAPM PMI**: ALFRED `series?seid=NAPM` redirects to the St. Louis Fed notice that ISM data were removed in June 2016. ISM data are licensed.
- **ALFRED `HELPWANT`, `GACDFNA066MSFRBPHI`** (Philadelphia Fed NSA series): both return 404 on the download form.
- **conference-board.org**: HTTP 503 on probe. LEI is licensed; the as-printed route is BCD on FRASER (sibling collectors).
- **EEI Weekly Electric Output history**: weo.eei.org says historical data are by contact only.
- **Daily Treasury Statement before 2005 on FRASER**: no title found. FRASER `/search?q=` returns 404/301 to a plain client (the search is script-driven), and the FRASER API needs a key.
- **web.archive.org, HathiTrust, files.nber.org**: not used (egress policy).
- **FRASER load**: three sibling collectors were fetching from FRASER at the same time (Economic Indicators, BCD, the weekly supplement 1947–76). I stopped my own 1947–48 weekly pull to avoid duplication and ran the 1977–81 gap at 2.5 s spacing.
